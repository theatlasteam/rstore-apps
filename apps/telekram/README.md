# Telekram 1.3.0 for KaiOS 2.5

Unofficial Telegram client by Cyan. This is the original upstream KaiOS 2.5 ZIP, without code or credential modifications. It is not a KaiOS 3/4 build.

License: GNU GPL v3; see LICENSE. Source and build scripts are available in [source.zip](source.zip) and at https://github.com/cyan-2048/solid-telekram/tree/69001285bd619cbf30fbe407dedb7bdbd654fb77. The source snapshot has the same manifest version; RStore has not independently reproduced this binary.

Install using RStore on a supported phone. This client connects to Telegram; Telegram login and account security remain under the user’s control. RStore does not receive login codes, passwords or chats. This mirror is not an endorsement or a privacy audit. Phone compatibility, sign-in and messaging have not been tested.

The manifest requests microphone, camera, contacts, SD-card access, notifications and networking. Review permissions before signing in. Upstream app language support is unchanged; only the RStore listing is localized.
